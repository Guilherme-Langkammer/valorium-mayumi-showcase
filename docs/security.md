# Security and Privacy

This repository is documentation-only. It intentionally excludes:

- Customer names, addresses, telephone numbers and order identifiers.
- Transaction details, sales totals and business performance figures.
- API tokens, passwords, keys, cookies and environment files.
- Private source code, internal endpoints and deployment configuration.

The dashboard preview uses opaque redaction blocks over sensitive operational areas, rather than a reversible image-layer effect. The original screenshot is not included.

Before publishing further images, review visible browser URLs, account names, emails, order details, customer information and any third-party brand assets. Obtain permission from the client for public use of the Mayumi name, logo and product photographs.
